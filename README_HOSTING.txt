🚀 HOSTINGER NODE.JS SETUP STEPS (Step-by-Step in Urdu):
------------------------------------------------------------------------

Step 1: File Upload
- Hostinger hPanel me log in karein.
- "File Manager" open karein aur `public_html` (ya apne domain folder) me ja kar `baryani-house-hostinger-deployment.zip` ko Extract karein.

Step 2: Node.js App Manager Setup
- hPanel dashboard me "Node.js" ya "Setup Node.js App" par click karein.
- Application Details me yeh options select karein:
  * Node.js Version    : 18.x ya 20.x
  * Application Mode   : Production
  * Application Root   : / (ya public_html)
  * Application Startup File : server.js

Step 3: Start Application
- "Save" ya "Create" par click karein.
- Hostinger automatic `server.js` run kare ga.
- Aap ki website 100% Live ho jaye gi!
